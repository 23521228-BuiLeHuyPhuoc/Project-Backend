# TourEx

## Tổng quan

Website đặt tour du lịch gồm trang khách hàng và trang quản trị. Hệ thống hỗ trợ tìm kiếm tour, giỏ hàng, đặt tour, thanh toán, voucher, đánh giá, thông báo và gợi ý tour cá nhân hóa.

## Công nghệ sử dụng

- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- Frontend: Pug, CSS, JavaScript, Tailwind CSS
- Xác thực: JWT, bcrypt, Express Session
- Dịch vụ: Cloudinary, Nodemailer, ZaloPay, VNPay
- Gợi ý tour: Content-Based Filtering, Collaborative Filtering, TensorFlow.js
- Triển khai: Vercel
